# 🎁 A Present from Mopeli Mopeli

An interactive, enchanted 22nd birthday card for Andiswa — a glowing gift box that opens to a blooming bouquet, fireworks, petals and chimes.

## View it
Live (after enabling GitHub Pages): `https://<your-username>.github.io/andiswa-birthday/`

Or just open `index.html` in a browser (needs internet for Tailwind and Google Fonts).

## Tech
Single-file HTML, Tailwind CSS (CDN), Canvas animations, Web Audio chimes.
